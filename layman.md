Content-Security-Policy (CSP) is a browser security setting that tells a website which scripts, images, and other resources are allowed to load — preventing attackers from injecting malicious code. `cspbuilder` is a command-line tool that does two things: it reads an HTML page and automatically generates the tightest-possible CSP based on what that page actually loads, and it audits an existing CSP header to flag common weaknesses like wildcard permissions or unsafe settings. It runs entirely on your machine with no account or cloud service needed, and is aimed at web developers and security teams who want to harden their sites quickly.
